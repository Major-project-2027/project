# face-recognition depends on dlib, which has no prebuilt wheel on PyPI
# for Windows (any Python version) -- installing plain `dlib` here means
# pip tries to build it from source, which needs a C++ toolchain + cmake
# and will fail on a normal dev machine. dlib-bin ships prebuilt Windows
# wheels (including cp313) under a different distribution name but
# installs the same importable `dlib` module, so face-recognition just
# works against it with no compiler needed. Install dlib-bin BEFORE
# face-recognition (or use `pip install face-recognition --no-deps` +
# dlib-bin) so pip never attempts the real `dlib` package on Windows.
